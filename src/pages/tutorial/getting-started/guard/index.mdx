# Guard

When you need to apply multiple hooks to your application, instead of repeating hooks multiple times, you can use `guard` to bulk add hooks to your application.

```typescript ins={13-25} del={4-12}
import { Elysia } from 'elysia'

export const app = new Elysia()
	.onBeforeHandle(({ headers: { authorization }, status }) => {
		if(!authorization) return status(401)
	})
	.onBeforeHandle(({ query: { name } }) => {
		console.log(name)
	})
	.onAfterResponse(({ responseValue }) => {
		console.log(responseValue)
	})
	.guard({
		beforeHandle: [
			({ headers: { authorization }, status }) => {
				if(!authorization) return status(401)
			},
			({ query: { name } }) => {
				console.log(name)
			}
		],
		afterResponse({ responseValue }) {
			console.log(responseValue)
		}
	})
	.get('/auth', ({ query: { name = 'anon' } }) => `Hello ${name}!`)
	.get('/profile', ({ query: { name = 'anon' } }) => `Hello ${name}!`)

if (import.meta.main) app.listen(3000)
```

Not only that, you can also apply **schema** to multiple routes using `guard`.

```typescript ins={16-18} del={22-26,31-35}
import { Elysia, t } from 'elysia'

export const app = new Elysia()
	.guard({
		beforeHandle: [
			({ headers: { authorization }, status }) => {
				if(!authorization) return status(401)
			},
			({ query: { name } }) => {
				console.log(name)
			}
		],
		afterResponse({ responseValue }) {
			console.log(responseValue)
		},
		query: t.Object({
			name: t.String()
		})
	})
	.get(
		'/auth',
		{
			query: t.Object({
				name: t.String()
			})
		},
		({ query: { name } }) => `Hello ${name}!`
	)
	.get(
		'/profile',
		{
			query: t.Object({
				name: t.String()
			})
		},
		({ query: { name } }) => `Hello ${name}!`
	)

if (import.meta.main) app.listen(3000)
```

This will apply hooks and schema to every route **after .guard** is called in the same instance.
