# Welcome to Elysia

It's great to have you here! This playground will help you get started with Elysia interactively.

Each lesson comes with a code editor that runs your code with Bun, so there's nothing to install. It's a perfect environment for learning and experimentation.

You can open the API docs at any time with the **Docs** tab at the top of this pane, or by clicking a <IconBookmark className="inline" size={18} stroke={2} /> link in the text.

## What is Elysia

Elysia is an ergonomic framework for humans.

Ok, seriously, Elysia is a backend TypeScript framework that focuses on developer experience and performance.

What makes Elysia different from other frameworks is:

1. Spectacular performance comparable to Golang.
2. Extraordinary TypeScript support with **type soundness**.
3. Built around OpenAPI from the ground up.
4. Offers End-to-end Type Safety like tRPC.
5. Uses Web Standards, allowing you to run your code anywhere like Cloudflare Workers, Deno, Bun, Node.js and more.
6. It is, of course, **designed for humans** first.

Although Elysia has some framework-specific concepts to learn, once users get the hang of it, many find it very enjoyable and intuitive to work with.

## How to use this playground

Playground is divided into 2 sections:
1. Documentation and assignments on the left side (what you're currently reading).
2. Code editor on the right side, which runs your code.

Assignments are checked as you edit the code: each one sends requests to your app and is ticked once the response is right. If you're stuck, open **Show answer** below the assignments.

Every lesson's code looks like this:

```typescript
import { Elysia } from 'elysia'

export const app = new Elysia()
	.get('/', 'Hello World!')

if (import.meta.main) app.listen(3000)
```

The app is exported so the assignments can import it and send it requests without starting a server. `import.meta.main` is only true when the file runs directly, like `bun index.ts`, so that's the only time `listen` starts the server.
